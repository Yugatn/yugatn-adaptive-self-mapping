# YASMP Research Program

## Experiment A — Sociometric dynamics

Question:

Does a subject's relational position change systematically across contexts?

Design:

Repeated sociometric measurements across at least several contexts and time points.

Primary outputs:

- reciprocity;
- centrality;
- density;
- relational diversity;
- stability;
- context sensitivity.

## Experiment B — Symbolic blind test

Question:

Do symbolic profiles perform better than generic or random profiles when source labels are hidden?

Conditions:

1. true symbolic profile;
2. generic Barnum-style profile;
3. randomized profile;
4. evidence-based control profile where appropriate.

Primary outcomes:

- perceived accuracy;
- specificity;
- usefulness;
- discrimination between conditions.

## Experiment C — Astronomical incremental validity

Question:

Do astronomical variables add predictive information beyond ordinary temporal and environmental variables?

Model A:

calendar time + season + relevant environmental controls.

Model B:

Model A + astronomical variables.

Validation:

Use temporal holdout or independent data.

Interpretation:

A reproducible improvement supports incremental predictive value only. It does not establish astrological causation.

## Experiment D — Contextual social field

Question:

Can social-network changes be predicted from contextual variables without reducing the subject to a fixed type?

Variables may include:

- group;
- role;
- activity;
- time;
- environmental state;
- self-reported state;
- previous network state.

Astronomical variables are optional additional predictors.

## Experiment E — Agency Gain

Question:

Does using an adaptive self-map improve the subject's ability to make choices?

Measure before and after an intervention:

- perceived choice;
- ability to identify alternatives;
- autonomy;
- environmental fit;
- communication quality;
- willingness to revise a self-description.

A decrease in agency is a negative result even if predictive accuracy increases.

## Research discipline

All confirmatory hypotheses should be registered before analysis.

Exploratory findings must remain labelled exploratory.

Negative results are retained.

Multiple testing must be controlled or transparently reported.

A result is not accepted merely because it is statistically significant.
